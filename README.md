# Laboratorio 01 — Primeros pasos con Java

Repositorio correspondiente al desarrollo de las prácticas y el reto integrador del **Laboratorio 1** del proceso formativo en Java.

## 📂 Estructura del Proyecto
El repositorio contiene los archivos fuente (`.java`) organizados de las prácticas básicas y el reto integrador:
- `HolaJava.java` — Verificación del entorno y primera ejecución.
- `DatosBasicos.java` — Declaración de variables y tipos de datos.
- `Inventario.java` — Modificación de estados en variables.
- `Operadores.java` — Operadores aritméticos y expresiones.
- `Saludo.java` — Entrada de datos mediante la clase `Scanner`.
- `CotizadorCompra.java` — Reto integrador (cálculo de subtotal, descuentos, impuestos y total final).

---

## 🚀 Cómo Ejecutar los Programas

Para compilar y ejecutar cualquiera de los programas desde la terminal, asegúrate de tener instalado el **JDK 21** (o superior) y sigue estos pasos:

### 1. Compilar el archivo `.java`
Ubícate en la carpeta del laboratorio en tu terminal y ejecuta el comando `javac` seguido del nombre del archivo:
```bash
javac NombreDelArchivo.java
